## Состояние

Окружение подготовлено. `catalog_analysis.py` пока содержит только сообщение о готовности; функции девяти этапов ещё предстоит реализовать.

## Запуск и проверка

Откройте этот каталог как отдельную папку в VS Code. Из терминала в корне проекта:

```powershell
uv sync
uv run catalog_analysis.py
uv run ruff check .
```

`uv` создаёт локальное `.venv`. Оно используется только этим заданием; в Git попадают `pyproject.toml` и `uv.lock`, но не `.venv`.
