Страница может требовать входа в Практикум. Исходный список фильмов приведён в начале `catalog_analysis.py`; программа не загружает внешние данные.

## Что реализовано

Функции девяти этапов считают рейтинг и возраст фильмов, работают со строками, циклами, списками, словарями, множествами и генератором. `build_report(movies)` собирает итог: средний рейтинг и возраст, три фильма с наивысшим рейтингом, количество фильмов по жанрам и алфавитный список жанров.

`top_n_by_rating()` возвращает кортежи `(title, rating)`, как требует этап 5. Для строк итогового отчёта используются полные записи фильмов: в них также есть год, длительность и жанры.

## Запуск

Нужны `uv` и Python 3.12.10 (версия закреплена в `.python-version`). Из корня этого репозитория:

```powershell
uv sync
uv run catalog_analysis.py
uv run ruff check .
```

`ruff` — зависимость для разработки; другие сторонние библиотеки не используются. `uv` создаст локальное окружение `.venv`, которое не входит в репозиторий.

Демонстрация генератора из этапа 8 запускается отдельно, чтобы обычный запуск выводил только итоговый отчёт:

```powershell
uv run python -c "from catalog_analysis import movies, demonstrate_iter_high_rated; demonstrate_iter_high_rated(movies)"
```
